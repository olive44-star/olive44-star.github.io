    How The Web Works

    The web works by using these 3 terms:

    • DNS
    • HTTP/HTTPS
    • JSON
    • Browser
    • Response
    • Request

    Term Explanation Example
    DNS(Domain Name System) Finds the IP address for a website name google.com → 142.250...
    HTTP/HTTPS(Hyper Text Transfer Protocol) Rules for sending information between your browser and a website. HTTPS encrypts data between a web brower and a website Opening https://google.com
    JSON It is an open standard file format and interchange that uses human readable texts to store and trnsmit data objects consisting of arrays and name value pairs. { "id": 101, "name": "Jane Doe", "isActive": true, "roles": ["Admin", "User"], "contact": { "email": "jane.doe@example.com", "phone": "555-0199" } }
    Browser An app used to access websites. Chrome, Safari, Edge
    Server A computer that stores websites and sends information to users. A web server hosting a website
    Request A message your browser sends asking for something. Asking for a webpage
    Response The information the server sends back. The webpage being sent to your browser

    What is FastAPI?

    FastAPI is a modern, fast (high-performance) web framework for building APIs with Python based on standard Python type hints. It is one of the most popular tools for creating backend services, particularly for machine learning applications, data science, and microservices.

    What does it look like?

    Quick FastAPI code looks like this:

    • from fastapi import FastAPI
    • app = FastAPI()
    • @app.get("/") def read_root(): return {"message": "Hello World"}

    When you run this code, it immediately sets up a web server and builds an interactive documentation page for you at http://127.0.0

    Break down of the code:

    • @app.get("/") is the Decorator: It tells FastAPI that the function right below it is responsible for handling web requests that go to the main web address ( the "/" path) using the HTTP GET method.
    • def read_root(): is the function: This is the standard Python function that executes whenever a user or application visits that path.
    • return {"message": "Hello World"} is the response: This is the data the function sends back to the user. FastAPI automatically converts this Python dictionary into a standard JSON object.
      • FastAPI can be used to generate some HTTPS status codes

      They are sent by the web server in the HTTP header to tell your browser or app whether the web request was successful or if an error occurred. While the code itself lives in the header, developers often repeat it inside the JSON response body so the app can read it easily.

      The 5 Categories of HTTP Status Codes:

    • 1xx (Informational): The request was received, and the process is continuing.
    • 2xx (Success): The action was successfully received, understood, and accepted (e.g., 200 OK or 201 Created).
    • 3xx (Redirection): Further action needs to be taken to complete the request (e.g., 301 Moved Permanently).
    • 4xx (Client Error): The request contains bad syntax or cannot be fulfilled (e.g., 404 Not Found or 401 Unauthorized).
    • 5xx (Server Error): The server failed to fulfill an apparently valid request (e.g., 500 Internal Server Error)

    Setting up in GitHub

    • Configure GitHub Settings:Do this first to prevent domain takeover risks.
    • Navigate to your repository on GitHub and click Settings.
    • In the left sidebar under "Code, planning, and automation", click Pages.
    • Scroll down to Custom domain, enter your domain (e.g., example.com), and click Save.

    Updating DNS Record

    Completed at your domain registrar (e.g., Namecheap, GoDaddy). Log into your domain provider's dashboard, locate the DNS management section, and add the following records:

    Type Host/Name Value/Target
    A @ 185.199.108.153
    A @ 185.199.109.153
    A @ 185.199.110.153
    A @ 185.199.111.153
    CNAME WWW username.github.io (replace with your GitHub username)

    Enforce HTTPS

    • Wait for the DNS changes to propagate (often takes 15–30 minutes, but can take up to 24 hours).
    • Return to your repository's Settings > Pages screen.
    • Check the Enforce HTTPS box. This provisions a certificate to ensure your site is secure and redirects HTTP traffic to HTTPS automatically.

    Preparing And Submitting A Good Application

      Research The Basics

    1. The Employer: Study the company’s website and social media. Know what products or services they provide and understand their core company values
    2. The Role: Re-read the job description carefully. Highlight the top three skills they want, so you can mention them in your answers.
    3. The Qualification: Know exactly which apprenticeship level you are applying for (e.g., Level 2, Level 3, or a Degree Apprenticeship). Be ready to explain why you want to split your time between working and studying

      Master the "STAR" Method

      When asked to give examples of your skills, do not just say you are a good team player. Prove it by structuring your answers using the STAR method:

    1. S - Situation: Set the scene (e.g., "During a school group project..." or "When I was captain of my local football team...").
    2. T - Task: Describe the problem or goal you faced.
    3. A - Action: Explain exactly what you did to help or solve it.
    4. R - Result: Share the positive outcome and what you learned from the experience.
